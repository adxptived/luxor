# Luxor — QoL-улучшения (pass 5)

Запрос: «дальше улучшай и не только хоткеями». Этот заход — про видимый UI/UX,
а не про сочетания клавиш.

## Статус-бар редактора (как в VS Code)
В нижнюю панель редактора файлов добавлена живая строка состояния:

- **Позиция курсора** — `Ln 12, Col 5`, обновляется на лету. **Клик по ней
  открывает «Перейти к строке»** (то же, что Ctrl+G) — удобно прыгать по файлу
  мышью.
- **Размер выделения** — показывает `(N выделено)`; при мультикурсоре —
  `(N выделено в K диапазонах)`.
- **Язык файла** — `TypeScript`, `Rust`, `Markdown` и т.д. (по расширению).

## Кнопка «Формат»
Рядом с Undo/Redo/Wrap появилась кнопка **«Формат»** — форматирует текущий
документ (встроенные форматтеры Monaco: JSON / JS / TS / CSS / HTML). То же
доступно по Shift+Alt+F.

## Заметка про насыщенность приложения
Проверил панели файлов и изображений — они уже очень богатые (быстрый фильтр,
скрытые файлы, «свернуть всё», навигация стрелками, мультивыбор для агента,
контекстное меню; у изображений — зум/вписать/зум колесом). Поэтому не стал
дублировать — сфокусировался на реально недостающем: строка состояния редактора.
