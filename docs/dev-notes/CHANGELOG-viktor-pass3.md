# Luxor — улучшения (pass 3)

## SQL: просмотр и редактирование баз данных (панель `DbPanel`)

Полностью переписана панель работы с SQLite (`src/panels/DbPanel.tsx`).

### Вкладка «Данные»
- Сортировка по любому столбцу (клик по заголовку: вкл/убыв/выкл).
- Поиск/фильтр строк (LIKE по всем столбцам, с debounce).
- Редактирование ячеек прямо в таблице (двойной клик; Enter — сохранить, Esc — отмена).
- Добавление строки (модальное окно с полями и чекбоксами NULL).
- Удаление строки (с подтверждением).
- Контекстное меню по ПКМ: копировать значение, копировать строку как JSON, показать значение целиком, редактировать, установить NULL, удалить строку.
- Просмотр длинных значений в модальном окне (с авто-форматированием JSON).
- Экспорт в CSV / JSON.
- Выбор размера страницы (50/100/200/500) и пагинация.
- Редактирование доступно только для таблиц с rowid (таблицы WITHOUT ROWID — только чтение, помечены).

### Вкладка «Структура»
- Столбцы: имя, тип, NULL/NOT NULL, значение по умолчанию, первичный ключ.
- Список индексов.
- DDL (CREATE TABLE).

### SQL-консоль
- История запросов (хранится в localStorage, безопасный разбор JSON).
- Время выполнения запроса (мс) и число строк.
- Экспорт результата в CSV / JSON.
- Запись (INSERT/UPDATE/...) — только при явном включении галочки.
- Ctrl+Enter — выполнить.

### Бэкенд (Rust — требует сборки на вашей машине)
Новые/изменённые функции в `crates/luxor-core/src/fsx.rs` и команды в
`src-tauri/src/commands/fsx.rs` (зарегистрированы в `src-tauri/src/lib.rs`):
- `db_rows` — добавлены сортировка, фильтр (параметризованный LIKE), rowid и флаг editable.
- `db_table_info` — схема таблицы (столбцы, индексы, DDL, число строк).
- `db_update_cell`, `db_insert_row`, `db_delete_rows` — редактирование.
- Параметризованные запросы (защита от SQL-инъекций), запись через `open_db_writable`.
- Добавлены unit-тесты (`cargo test -p luxor-core`).

## Общие QoL-улучшения (не только SQL)

- **Редактор**: переключатель переноса строк (Word wrap) — кнопка в нижней панели
  и горячая клавиша **Alt+Z** (как в VS Code). Настройка запоминается между сессиями.
- **БД**: запоминается последняя открытая таблица, размер страницы и последний
  SQL-запрос — для каждой базы отдельно.
