# Luxor — QoL-улучшения (pass 4)

Запрос: «делай qol апдейт, всякие ctrl+z в редакторе файлов и тд, чтобы
программой было очень удобно пользоваться».

## 1. Undo / Redo в редакторе файлов
- **Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z уже работают** в редакторе — это встроено в
  движок Monaco (как в VS Code). Также сразу доступны: поиск **Ctrl+F**, замена
  **Ctrl+H**, переход к строке **Ctrl+G**, мультикурсор (**Alt+click** /
  **Ctrl+D**), дублирование строки (**Shift+Alt+↓**), перемещение строки
  (**Alt+↑/↓**), комментирование (**Ctrl+/**).
- Добавлены **кнопки «Отменить»/«Повторить»** в нижнюю панель редактора — для тех,
  кто работает мышью (горячие клавиши при этом никуда не делись).

## 2. Открыть закрытую вкладку — Ctrl+Shift+T
Как в браузере / VS Code. Случайно закрыли вкладку (файл, терминал, diff, любую
панель) — нажмите **Ctrl+Shift+T**, и она вернётся.
- Стек закрытых вкладок хранится **отдельно для каждого проекта** (до 20 штук).
- Файлы/изображения/БД/PDF восстанавливаются по пути; diff — по параметрам;
  терминал — с тем же рабочим каталогом; панели (Git, Files и т.д.) — заново.
- Дубликаты одного и того же файла не копятся в стеке.

## 3. Закрыть активную вкладку — Ctrl+W
- Закрывает текущую вкладку (с подтверждением, если есть несохранённые правки —
  через тот же `dirtyGuard`).
- **Безопасно для терминала**: если фокус в терминале, **Ctrl+W = удалить слово**
  (readline), как и положено — вкладка при этом НЕ закрывается. То же для обычных
  полей ввода. В редакторе Monaco — закрывает вкладку (как в VS Code).
- Окно приложения этим сочетанием закрыть нельзя (перехватывается).

## 4. Команды и горячие клавиши
- В **командной палитре** (Ctrl+Shift+P / F1) появились «Вкладка: открыть закрытую
  вкладку» и «Вкладка: закрыть активную вкладку».
- В **Настройки → Горячие клавиши** добавлены «Close tab» (Ctrl+W) и
  «Reopen closed tab» (Ctrl+Shift+T) — их можно переназначить.

  `closeActivePanel`; `closePanelGuarded` теперь запоминает закрытую вкладку;
  хелперы `closableFromPanel` / `panelComponent`.

- `src/components/CommandPalette.tsx` — команды реоткрытия/закрытия вкладки.
- `src/panels/EditorPanel.tsx` — кнопки Undo/Redo.
- `src/lib/i18n.ts` — переводы новых строк (RU).
