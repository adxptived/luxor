## 🐛 Критический баг: «Failed to save settings: invalid type: floating point …, expected u16»

**Причина.** При перетаскивании границы сайдбара ширина считалась из `clientX`,
который на hi-DPI/масштабе дробный (например `248.81817626953125`). Это дробное
значение писалось в поле `sidebar_width`, которое в Rust — `u16`. При следующем
`config_set` serde падал с «expected u16».

**Исправлено в двух местах (защита у источника + централизованно):**
- `src/components/TopBar.tsx` — `startResize.onMove` теперь оборачивает ширину в
  `Math.round(...)`.
- `src/lib/ipc.ts` — добавлен `sanitizeConfig()`, который перед каждым
  `config_set` округляет дробные значения целочисленных UI-полей
  (`topbar_size`, `sidebar_width`, `side_panel_width`, `right_panel_width`,
  `ui_font_scale`). `zoom` намеренно оставлен float. Теперь ошибка не вылезет
  ни из одного пути сохранения.

  скроллится, но полосы не видно).

## 2️⃣ Меню «+» больше не прячется под другими элементами
- **Причина.** Меню рендерилось `position: absolute` внутри полосы вкладок с
  `overflow`, поэтому обрезалось/уходило под соседний UI.
- **Исправлено** (`TopBar.tsx`): кнопка «+» по клику вычисляет координаты из
  `getBoundingClientRect()`, меню теперь `position: fixed` с `zIndex: 70`
  (вертикальный сайдбар → открывается вправо, горизонтальная панель → вниз),
  с защитой от выхода за край экрана. Меню осталось DOM-потомком кнопки, поэтому
  «клик вне → закрыть» и e2e продолжают работать.

## 3️⃣ Плавный скролл во всех вкладках
- `src/styles.css` — `scroll-behavior: smooth` расширен на `html, body` и
  варианты `overflow-{,y-,x-}scroll`. Терминал (`.xterm`) и Monaco-редактор
  явно исключены (`scroll-behavior: auto`), чтобы не лагал быстрый вывод/большие
  файлы.
- ⚠️ Замечание: CSS `smooth` сглаживает программный/клавиатурный скролл, но НЕ
  инерцию колеса мыши. Если хочешь «настоящую» инерцию колеса — это отдельная
  JS-библиотека, могу добавить отдельно.

## 4️⃣ Миникарта в файлах: понятнее, где ты, и без багов
- `src/panels/EditorPanel.tsx` — конфиг миникарты при создании И при
  переключении (`updateOptions`) теперь задаётся полным объектом:
  `{ enabled, showSlider: "always", renderCharacters: false,
  size: "proportional", maxColumn: 100 }`.
  `showSlider: "always"` всегда показывает рамку видимой области («где я»),
  полный объект при тоггле не даёт настройкам сбрасываться в дефолт.
