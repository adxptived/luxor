## Git / GitHub

- **Создание PR из UI** (Pulls-таб): форма head/base/draft c префиллом текущей ветки. Полный стек: `luxor-core::github::pull_create` -> Tauri `github_pull_create` -> IPC `githubPullCreate`. **Rust не компилировался в песочнице — проверьте `cargo check` локально.**
- **3-way merge UI** в ConflictsView: панели ours/base/theirs над редактируемым результатом, переключатель.
- **Граф коммитов**: SVG теперь наложен на строки коммитов на общей сетке (узлы совпадают со строками), добавлены чипы веток.

## Терминал

- Кликабельные пути файлов в выводе (`src/a.rs:12:34`, `./b.ts:5`, `C:\x\a.rs(7,2)`): Ctrl+Click открывает файл в редакторе на нужной строке (`lib/terminalLinks.ts` + 9 тестов).
- Кнопка «Остановить процесс» (SIGINT/Ctrl+C): в углу терминала при активном foreground-процессе + пункт контекстного меню.

## Редактор / файлы

- **Hex-просмотр бинарных файлов**: вместо ошибки «not a text file» открывается read-only hex-дамп (offset/hex/ascii, чанки по 64 КиБ, «Загрузить ещё») — `components/HexView.tsx`.
- **Bulk-удаление** в проводнике: кнопка Delete в панели мультивыбора, одно подтверждение на всё, закрытие затронутого встроенного редактора, отчёт об ошибках.

## HTTP
