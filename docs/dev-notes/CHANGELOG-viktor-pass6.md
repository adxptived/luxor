# Luxor — QoL-улучшения (pass 6)

Запрос: «поиск по всем файлам (Ctrl+Shift+F UI), drag&drop вкладок/файлов,
«Сохранить всё» — делай это всё».

## 1. Поиск по проекту (Ctrl+Shift+F)
Панель поиска и замены уже была (regex / регистр / замена по файлам). Доработал
именно UX:

- **Автофокус поля ввода** при открытии — нажал Ctrl+Shift+F и сразу печатаешь.
- **Переход на точную строку**: клик по результату теперь открывает файл и
  **прыгает на нужную строку** (курсор + прокрутка по центру), а не просто
  открывает файл. Клик по заголовку файла ведёт на первое совпадение.

## 2. «Сохранить всё» (Ctrl+Alt+S)
- Новый общий реестр редакторов `src/lib/editorBus.ts`: каждый открытый редактор
  регистрируется, команда сохраняет все «грязные» (несохранённые) файлы разом.
- Доступно **тремя способами** (не только хоткей): командная палитра
  («Файл: Сохранить все файлы»), хоткей **Ctrl+Alt+S** (настраивается в
  Settings → Hotkeys), тост с итогом «Сохранено файлов: N» / «Нет
  несохранённых изменений».

## 3. Drag & drop файлов
- Файлы в проводнике теперь **перетаскиваются**: тащишь файл из дерева на область
  редактора → он открывается во вкладке.
- Использован собственный MIME `application/x-luxor-file`, чтобы **не ломать**
  встроенный drag&drop вкладок dockview (вкладки и так перетаскиваются/делятся
  на сплиты нативно).
