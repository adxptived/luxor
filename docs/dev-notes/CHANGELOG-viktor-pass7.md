# Luxor — Drag & drop файла в терминал (pass 7)

Запрос: «драг энд дроп в терминал есть? типа путь писать до файла и тд».

Раньше — нет. Теперь есть.

## Что сделал
- Перетаскиваешь файл из проводника (или из ОС) **на терминал** → в текущую
  строку вставляется **путь до файла**. Команда **не выполняется** — путь просто
  печатается у курсора, можно дописать команду и нажать Enter сам.
- Несколько файлов сразу → пути через пробел.
- **Авто-кавычки**: пути с пробелами/спецсимволами оборачиваются в кавычки
  (`"/home/My Files/a.txt"`), Windows-пути (`C:\Users\…`) остаются как есть.
- Источник — наш файл из дерева (MIME `application/x-luxor-file`) или
  нативный drop файла из ОС (в Tauri берётся абсолютный путь).

## Код
- `src/lib/shellQuote.ts` — чистая функция экранирования пути для шелла
  (+ тесты `shellQuote.test.ts`, 3 шт).
- `src/panels/TerminalPanel.tsx` — `onDragOver`/`onDrop` на контейнере
  терминала, вставка через `term.paste(...)`.
